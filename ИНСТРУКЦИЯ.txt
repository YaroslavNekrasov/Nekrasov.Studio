==================================================
 КАК ВКЛЮЧИТЬ ОТПРАВКУ ЗАЯВОК НА ПОЧТУ И ВЫЛОЖИТЬ САЙТ
==================================================

Всего 2 больших шага. Делается за 15 минут. Сервер НЕ нужен.


--------------------------------------------------
ШАГ 1. ПОЛУЧИТЬ КЛЮЧ ДЛЯ ОТПРАВКИ ПОЧТЫ (5 минут)
--------------------------------------------------

1. Открой сайт:  https://web3forms.com

2. На главной странице найди поле "Email Address"
   (Введите ваш email).

3. Впиши туда почту, НА КОТОРУЮ хочешь получать заявки.
   Например:  nekrasov.studio@mail.ru

4. Нажми кнопку "Create Access Key".

5. На указанную почту придёт письмо с КЛЮЧОМ.
   Ключ выглядит примерно так:
   a1b2c3d4-5e6f-7890-abcd-ef1234567890

6. Скопируй этот ключ (он понадобится в шаге 2).


--------------------------------------------------
ШАГ 2. ВСТАВИТЬ КЛЮЧ В САЙТ (3 минуты)
--------------------------------------------------

Ключ нужно вставить в ДВА файла:
   - index.html
   - Nekrasov Studio.dc.html

Для каждого файла:

1. Кликни по файлу ПРАВОЙ кнопкой мыши ->
   "Открыть с помощью" -> "Блокнот".

2. Нажми Ctrl+H (Найти и заменить).

3. В строку "Найти" вставь:
   ВСТАВЬТЕ_ВАШ_КЛЮЧ_СЮДА

4. В строку "Заменить на" вставь свой ключ из шага 1.
   ВАЖНО: кавычки трогать не нужно, только текст внутри.

5. Нажми "Заменить все".

6. Сохрани файл (Ctrl+S) и закрой.

Повтори то же самое со вторым файлом.

ПРОВЕРКА: открой index.html двойным кликом, заполни форму,
нажми "Обсудить проект". Через пару секунд письмо должно
прийти на твою почту. (Нужен интернет.)


--------------------------------------------------
ШАГ 3. ВЫЛОЖИТЬ САЙТ В ИНТЕРНЕТ (5 минут, бесплатно)
--------------------------------------------------

Самый простой способ - Netlify Drop (без регистрации сложной):

1. Открой:  https://app.netlify.com/drop

2. Перетащи мышкой ВСЮ папку "NekrasovStudio" целиком
   в окно браузера (туда, где написано "Drag and drop").

3. Подожди минуту. Netlify выдаст ссылку вида:
   https://random-name-12345.netlify.app

4. Готово! По этой ссылке твой сайт доступен всем в мире.

5. (Необязательно) Чтобы поменять адрес на красивый или
   подключить свой домен - зарегистрируйся на Netlify
   бесплатно и зайди в настройки сайта (Site settings ->
   Domain management).


--------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
--------------------------------------------------

- Письмо не приходит -> проверь, что ключ вставлен в ОБА
  файла и кавычки на месте. Проверь папку "Спам".

- Форма пишет "Ошибка сети" -> проверь интернет.

- Сайт открывается пустым -> нужен интернет (сайт
  подгружает часть кода из сети при открытии).
